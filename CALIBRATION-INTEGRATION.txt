CALIBRATION PERFORMANCE — INTEGRATION KE calibration.service.ts
===============================================================

Kenapa file ini berupa integrasi kecil dan BUKAN replacement calibration.service.ts?
Karena calibration.service.ts Anda sudah mengalami Round 1 -> Round 2 -> Round 2.1
-> Round 3 OOS. Mengganti seluruh file dari snapshot lama berisiko menghapus genuine
OOS / robust-validation yang sudah valid.

Yang harus dilakukan hanya mengganti jalur FETCH Yahoo 5y yang dipakai provider
Calibration. Statistik, sample filtering, PIT, T+20, robust validation dan OOS TIDAK
boleh diubah.

1) Tambahkan import:

import { fetchCalibrationYahooHistory5y } from './calibration-yahoo-history.service';

2) Di calibration.service.ts cari kode yang mengambil OHLC Yahoo 5 tahun untuk ticker.
Cari salah satu marker berikut:

    fetchYahooHistory(ticker, '5y')

atau request langsung:

    query1.finance.yahoo.com/v8/finance/chart/

atau provider callback yang setara.

GANTI HANYA fetch 5y tersebut menjadi:

    const chart = await fetchCalibrationYahooHistory5y(ticker);

Jika kode lama misalnya:

    const chart = await fetchYahooHistory(ticker, '5y');
    if (!chart) return [];

maka menjadi:

    const chart = await fetchCalibrationYahooHistory5y(ticker);
    if (!chart) return [];

JANGAN mengubah parsing chart.history setelah baris tersebut.

3) Jika provider saat ini mengembalikan null/[] saat fetch gagal, PERTAHANKAN perilaku
itu. Calibration harus fail-closed untuk ticker yang datanya gagal; jangan membuat
harga sintetis dan jangan fallback ke current data.

4) Jangan membungkus seluruh calculateCalibrationObservations() dengan retry massal.
Batas concurrency berada pada loader per ticker sehingga Promise.all existing boleh
tetap ada: maksimal 6 fetch Yahoo aktif sekaligus.

5) Optional diagnostic:
import { calibrationYahooLoaderStats } from './calibration-yahoo-history.service';

Kemudian boleh log sekali per request:
console.info('[calibration.yahoo] loader', calibrationYahooLoaderStats());

JANGAN tampilkan statistik loader sebagai bagian model validation result karena itu
operational telemetry, bukan statistik model.
