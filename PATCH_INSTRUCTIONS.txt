SahamLens - Bank Evidence Integrity FAIL Fix
============================================

Fix yang ditutup sekaligus:
1. False-positive observed_date masa depan ketika PostgreSQL masih UTC tetapi collector sudah tanggal Asia/Jakarta.
2. Active conflicting metric groups yang tertinggal dari run collector lama.
3. Pencegahan conflict baru lintas run/source sebelum INSERT evidence.

FILE PATCH:
- scripts/audit-production-integrity.mjs
- scripts/collect-bank-metric-evidence-auto.mjs
- scripts/repair-bank-metric-evidence-integrity.mjs

SETELAH COPY/OVERWRITE:

1) Dry-run repair:
   cd /opt/sahamlens/app
   NODE_OPTIONS="--dns-result-order=ipv4first --no-network-family-autoselection" \
   node --env-file=.env.production scripts/repair-bank-metric-evidence-integrity.mjs

   Periksa:
   - Future active rows
   - Conflicting groups
   - Rows to supersede
   - Blocked manual issues

   Kalau Blocked manual issues = 0, lanjut confirm.

2) Confirm repair:
   NODE_OPTIONS="--dns-result-order=ipv4first --no-network-family-autoselection" \
   node --env-file=.env.production scripts/repair-bank-metric-evidence-integrity.mjs --confirm

   Target:
   VERIFY future_rows=0 conflict_groups=0
   PASS - active bank metric evidence kembali fail-closed dan conflict-free.

3) Audit ulang:
   node --env-file=.env.production scripts/audit-production-integrity.mjs

   Target: FAIL = 0.

CATATAN INTEGRITAS:
- Repair tidak mengedit angka evidence.
- Row bermasalah hanya diberi superseded_at + reason (audit lineage tetap ada).
- Jika konflik seluruhnya AUTO_COLLECTED, semua conflicting rows dinonaktifkan (fail closed), bukan memilih angka sembarang.
- Jika ada curated/manual evidence tunggal, auto evidence yang berbeda dinonaktifkan.
- Jika curated/manual evidence sendiri konflik, repair BERHENTI dan meminta review manual.
