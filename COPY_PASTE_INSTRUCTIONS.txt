CARA COPY-PASTE KE FOLDER MAIN
1. Backup folder aplikasi dan database terlebih dahulu.
2. Extract ZIP patch.
3. Copy SEMUA isi hasil extract ke root aplikasi SahamLens (folder yang berisi package.json).
4. Pilih overwrite/replace untuk file yang namanya sama.
5. JANGAN hapus file lain yang tidak ada di patch. Patch hanya berisi file yang berubah/baru.

WAJIB SETELAH COPY (VPS)
A. Masuk ke root aplikasi:
   cd /opt/sahamlens/app

B. Install dependency sesuai lockfile dan lakukan verifikasi source terlebih dahulu:
   npm ci
   npm run typecheck
   npm test
   npm run build

C. Jika langkah B berhasil, apply migration BARU 006 sebelum restart aplikasi:
   node --env-file=.env.production scripts/migrate-database.mjs --confirm

   Alternatif bila DATABASE_URL sudah diexport ke shell:
   npm run db:migrate

D. Restart service hanya jika langkah B dan C berhasil:
   sudo systemctl restart sahamlens
   sudo systemctl status sahamlens --no-pager

PENTING UNTUK HISTORI VALIDASI
- Row lens_radar_history lama yang belum punya universe_eligible akan FAIL-CLOSED dari
  Calibration/Backtest/TPCL sampai histori tersebut dibangun ulang dengan kode baru.
- Jalankan backfill LensRadar untuk window yang memang ingin divalidasi, contoh:
   node --env-file=.env.production scripts/backfill-lens-history.mjs \
     --start=2025-08-17 --end=2026-08-17
- Fundamental PIT harus berasal dari data yang benar-benar diketahui pada observed_date.
  Jangan mengisi data lama memakai quote/sharesOutstanding hari ini.
- Jika Anda memang mempunyai CSV PIT Q3-2024 s/d Q2-2025 di data/financials:
   node --env-file=.env.production scripts/backfill-fundamental-pit-v2.mjs --dir=data/financials
  Jalankan fundamental PIT SEBELUM membangun ulang LensRadar agar coverage historis ikut masuk.
