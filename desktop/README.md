# SahamLens Pro Native Desktop

Workstation & Financial Terminal untuk pasar modal Indonesia (BEI / IDX).

## Fitur Utama:
- **Frameless Pro Titlebar**: Drag window mulus, live IHSG ticker tape, dan movers real-time.
- **Interactive Candlestick Chart Engine**: Didukung indikator EMA20, EMA50, Volume Flow, dan bar replay simulator.
- **LensRadar Breakout**: Pemindaian kandidat lonjakan volume dan pola breakout sesi aktif.
- **Deep Fundamental**: Neraca keuangan XBRL PIT resmi BEI, ROE, PER, PBV, dan dividen.
- **LensAI Copilot Drawer**: Asisten AI kontekstual untuk analisis emiten dan valuasi.
- **Command Palette (`Ctrl + K`)**: Pencarian emiten global secepat kilat.

## Development:
```bash
npm install
npm run dev
```

## Build Desktop:
```bash
npm run build
npm run tauri build
```
