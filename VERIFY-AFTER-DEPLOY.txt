VERIFY SEO HOMEPAGE
===================

1. Merge metadata ke app/layout.tsx.
2. Pastikan favicon tetap ada:
   app/favicon.ico
   app/icon.png
   app/apple-icon.png
   dan/atau public/favicon.ico
3. Jalankan:
   npm run typecheck
   npm run build
4. Deploy Production.
5. Buka https://sahamlens.id/
6. View Source / DevTools <head>, pastikan:
   - title mengandung SahamLens
   - meta description ada
   - canonical = https://sahamlens.id/
   - og:title benar
   - og:url = https://sahamlens.id/
   - favicon benar
7. Pastikan root tidak memakai canonical /workspace.
8. Google Search Console:
   URL Inspection -> https://sahamlens.id/
   -> Test Live URL -> Request Indexing

Catatan:
Google tetap dapat menulis ulang title hasil pencarian. Metadata ini memperkuat
sinyal tetapi tidak memaksa title Google 100%.
